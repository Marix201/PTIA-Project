# Comparacion descriptiva con datos publicados

Fuente: Kupec et al. 2025 (n=175). Grupo sintetico: endo (n=504).

| Sintoma | Publicado | Sintetico |
|---|---|---|
| Dolor maximo (0-10), media (DE) | 7,25 (1,87) | 7,32 (1,63) |
| Dismenorrea | 96,6 % | 100,0 % |
| Dispareunia | 38,3 % | 89,3 % |

Validacion externa descriptiva. No se uso para entrenar el modelo ni para medir su desempeno, y la poblacion publicada es distinta a la simulada. La dispareunia sintetica cuenta cualquier dia con dolor en relaciones dentro del registro; el estudio publicado la mide una sola vez.
